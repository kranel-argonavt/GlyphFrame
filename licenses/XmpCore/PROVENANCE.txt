Historical contradictory Java notice and resolution:
The original Adobe 6.1.10 Maven POM declares BSD, while the JAR's META-INF/LICENSE
contains an Adobe confidential/proprietary notice. Initial investigation treated
this as unresolved. Apache Tika's public investigation records Leonard
Rosenthol's explanation that the build included an incorrect license file and
was being fixed; the Java 6.1.11 release corrected that packaging issue.
The .NET maintainer's accepted clarification above connects the port's own
license declaration to the recovered Adobe terms, rather than relying only on
a Java dependency upgrade performed by another project.
